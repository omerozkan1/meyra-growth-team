# Content Pillars

| | P1 Manevi farkındalık | P2 Pratik ibadet araçları | P3 Meyra ürün demoları |
|---|---|---|---|
| **Job** | Reach, saves, shares, trust | Solve a concrete problem; search traffic (Shorts) | Convert to installs |
| **Share** | 35% | 35% | 30% |
| **Segments** | S2, S3 | S1, S2, S4 | S1, S3 |
| **Format** | 15–25 s, calm b-roll + verse/reflection text, slow voice-over or text-only | 20–35 s, "3 adım/3 yol" listicle, real-world problem → solution | 20–30 s, 100% real screen recording, hand-held phone shot or clean capture |
| **App presence** | Last 3 s (soft) | Woven in as one of the solutions | Entire video |
| **CTA** | Soft: "Günlük hatırlatma için Meyra, link profilde" | Soft/direct | Direct: "Ücretsiz indir, link profilde" |
| **Risk** | Religious accuracy, so verse references must be verified | Fiqh rulings, so redirect to Diyanet/hoca | Feature accuracy, so only `config/brand.md` claims; show the real UI |

## Hook formulas (TR)
1. **Problem question:** "Otel odasında kıble nerede?"
2. **Relatable confession:** "Uzun zamandır namaz kılmıyordum…"
3. **Number promise:** "Namazı kaçırmamak için 3 ayar"
4. **Seasonal:** "Üç Aylar'a 1 hafta kala…"
5. **Myth-bust (gentle):** "Kur'an okumaya başlamak için geç değil."
6. **POV:** "POV: Ezan bildirimi telefonundaki en sakin bildirim."

## Series (repeatable formats)
- **"Küçük Adım"** (P1): one tiny spiritual habit per episode.
- **"Nasıl yapılır?"** (P2): one practical worship question per episode.
- **"Meyra'da 20 saniye"** (P3): one feature per episode.

## Format rules
- 9:16, 1080×1920, 30 fps, subtitles burned in (most people watch muted).
- First frame must already show the hook text (no logo intro).
- Keep 12% top and 20% bottom free of text (UI overlays).
- Music: platform library sounds on IG/TikTok; YouTube Audio Library for Shorts. No copyrighted recitation without permission. Use the app's own audio only if the owner confirms the rights.
- One master edit (no platform watermark), then upload natively to each platform. Never re-upload a TikTok file with its watermark.
