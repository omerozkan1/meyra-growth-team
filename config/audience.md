# Audience

> These segments are **[A] hypotheses** built from the store copy, the feature set and review themes. Validate them with Firebase demographics, store analytics and comment analysis in weeks 1–2.

## Market priority
1. **Turkey (TR)**: primary. Turkish content, TL pricing, Diyanet frame of reference.
2. **Turkish diaspora (DE, NL, AT, FR, UK)**: same Turkish content works; prayer-time accuracy abroad is a strong hook. **[A]**
3. **English-speaking Muslims**: phase 2 (after day 30).
4. **Arabic-speaking markets**: phase 3. Needs native creative and review.

## Segments

### S1: "Düzen arayan" (looking for routine), 25–40, urban, working
- Prays some or most prayers; misses some during work/commute.
- Pain: forgets times in winter (short days), notifications buried among other apps, cluttered ad-heavy apps.
- Hooks: "Kışın vakitler kaçıyor mu?", "İş yerinde kıble nerede?"
- Meyra angle: calm, clean prayer times + notifications, qibla, kaza tracking.

### S2: "Yeniden başlayan" (returning / beginner), 18–30
- Wants to start praying regularly or learn to read the Quran; feels "geç kaldım" (I'm too late).
- Pain: embarrassment, no starting point, doesn't know Arabic letters.
- Hooks: "Kur'an okumayı hiç bilmiyorum, nereden başlarım?", "Kendine yeniden başla".
- Meyra angle: Learn Quran from the letters, small steps, judgment-free tone.
- **Most aligned with the brand promise "Kendine yeniden başla".**

### S3: "Manevi rutin kuran" (building a spiritual routine), women and men 25–55
- Already practising; wants dhikr, dua, hatim, Esmaül Hüsna in one place.
- Hooks: tesbihat, hatim goals, kandil/üç aylar content, Cuma.
- Meyra angle: zikirmatik with goals, hatim tracking, dua/hadith collection.

### S4: Diaspora / travellers
- Pain: unreliable times abroad, qibla in hotels, finding mosques.
- Meyra angle: location-based times, qibla, nearby mosques.

## Where they are (organic)
- Instagram Reels: S1, S3 (strongest for Turkish religious lifestyle content)
- TikTok: S2 (younger, discovery-driven)
- YouTube Shorts: all; long-tail search ("kıble nasıl bulunur", "tesbihat nasıl yapılır")

## Language notes
- Use "sen" (informal). Use common Turkish terms: namaz, abdest, kıble, zikir, tesbihat, kaza, hatim.
- Spell religious terms consistently: Kur'an, Esmaül Hüsna, Diyanet, Ramazan, kandil, Üç Aylar.
